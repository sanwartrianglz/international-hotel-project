# 01_research

- `competitors/`: competitive analysis of housekeeping apps (e.g. Flexkeeping, Optii, HotSOS, Quore, Hotelkit) and chain staff apps. One file per product, plus `competitor-matrix.md`
- `users/`: what we learn about international housekeepers: languages, literacy, devices, pain points, any interviews
- `concept-brand/`: what "international" means, Cecil Hotel (Alexandria, 1929) heritage, how we differ from the Gulf and Nubian teams, localisation and RTL best practice

**Output:** key insights, which feed `02_define/`.
