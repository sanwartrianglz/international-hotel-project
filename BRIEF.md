# Project Brief: Cecil Hotel · International

**Team:** Sally · Salma · Amr **Lead UX:** Fawzia **Due:** week of 2026-11-16

## The assignment
Take the Cecil Hotel housekeeping operations concept and design it **for housekeepers** in an **international hotel** context. Two other teams do the same for a Gulf hotel and a Nubian hotel.

## What "international" means for us
- **Chain scale:** properties in several countries, sharing brand standards with local variations.
- **Multinational workforce:** housekeepers speak different languages and have different literacy levels.

## Features in scope
| Feature | Why it matters for an international housekeeper |
|---|---|
| Multi-language + Arabic RTL / LTR switching | Staff use the app in their own language |
| Icon- and visual-first UI | Works across languages and literacy levels; photos and colors carry meaning |
| Brand standards per country | One chain checklist, with local variations per property |
| Guest culture notes per room | e.g. prayer mat, no alcohol in the minibar, do-not-disturb habits, dietary needs |
| PMS-fed room status (assumed) | Checkouts and guest preferences arrive automatically |

## Baseline carried over from Cecil Hotel
Section-based assignment at shift start · room status flow (Dirty → Assigned → Cleaning → Cleaned → Inspected → Ready, plus Out of Order) · checklist per room type · issue reporting with photo · offline support · push notifications.

## Deliverables
1. Research: competitive analysis, Mobbin pattern references, concept & brand
2. Define: personas, feature list, RSD
3. Structure: sitemap, user flows
4. Design: branding, design system, hi-fi UI (Figma)
5. Prototype
6. Coded build
