House rules & requestslive site

This is Airbnb's closest built-in "checklist". Hosts pick from a fixed set of standard rules: guest count, pets, smoking, parties, lock up at checkout and a few more. Each rule shows as an icon tile and one short line. Hosts then add their own free-text requests ("During the stay", "Before checkout") underneath. Opened from Things to know → House rules → Show more.

Design idea for us: the split between standard items from a fixed list (which can be translated automatically and shown as icons) and a few free-text extras is how our room checklists should work. The chain's brand standard is the fixed list, and the property or supervisor adds short local notes on top. Standard rules translate perfectly; only the free text needs machine translation (see Translation pattern).
Not confirmed: some sources describe a separate predefined checkout task list (e.g. "throw rubbish away", "turn things off"). On the live site and in Airbnb's host resources I only found the "Lock up at checkout" rule plus free-text "before checkout" requests, so this page shows what was verified.
